## Issues Resolved During Deployment

### Port conflict (9090)
Dynamo Rust runtime's `spawn_system_status_server` hardcodes `0.0.0.0:9090`.  
**Fix:** Sidecar moved to port **9091** via `DYNAMO_RL_SIDECAR_PORT=9091` (env var injected into DGD CR; default changed in `rl_scaling_sidecar.py`).

### JSON parsing in test scripts
Python's `json.dumps` emits `"key": "value"` (space after colon); bash `grep -oE '"key":"val"'` (no space) failed silently under `set -e`.  
**Fix:** All JSON extraction patterns updated to `[[:space:]]*` in both `test-s2.sh` and `test-s3.sh`.

### test-s3 migrate_out design
`migrate_in` submits via fire-and-forget `engine_client.generate()` bypassing `InProcessRequestRegistry`, so `migrate_out` with a just-forged request_id always returns "unknown request_id".  
**Fix:** Redesigned step 2 to test `migrate_in` independently on SRC and DST, and use wildcard `"*"` for `migrate_out` (best-effort, skips gracefully when engine is idle).
